Assignment 01: How the Web Works

When we type a URL in a web browser and press Enter, several steps take place:

1. URL: The browser reads the URL to identify the website we want to visit.
2. DNS Lookup: DNS converts the domain name into an IP address.
3. Connection: The browser establishes a connection with the web server, usually using TCP and TLS for HTTPS.
4. HTTP Request: The browser sends an HTTP request to the server.
5. Server Response: The server processes the request and sends back the requested resources, such as HTML, CSS, JavaScript, and images.
6. Rendering: The browser parses HTML, applies CSS, executes JavaScript, and renders the webpage on the screen.

Conclusion: These steps allow us to access and view websites in a browser.
